## Script using only known signs

1. `H-I` (fingerspelled) → "Hi."
2. `HELP` → "Can you help me?"
3. `F-O-R-C-E`, hands down, then `MEAN` → "What does force mean?" (shows the FORCE diagram)
4. `UNDERSTAND` → "I understand." (THANK-YOU would show as `?`)

Each line is either all signs or all fingerspelling; put hands down between them.
